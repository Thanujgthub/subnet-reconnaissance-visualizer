# Verification inventory

The application is a scrollable educational experience. The opening view must show the project identity, core networking premise, working exploration links, and an illustrative topology. Scrolling is intentional.

| Feature / claim | Functional evidence | Visual evidence |
|---|---|---|
| Responsive navigation | Every anchor resolves; active section; mobile open/close/Escape | Desktop and mobile header |
| Genuine 3D topology | WebGL canvas initializes; pause/resume; inspect all six hosts | Desktop hero; mobile SVG fallback |
| Subnet Explorer | Live inputs, examples, Calculate, copy, invalid state | /24, /31, /32, /0, invalid input |
| Accurate address arithmetic | Unit tests for every prefix and unsigned limits | Calculated bit and address ranges |
| Eight-stage workflow | Select all eight; previous/next bounded | Selected-stage detail and data flow |
| TCP explanation | All four outcomes selectable | Acceptance, refusal, timeout, error diagrams |
| Deterministic simulation | Start → discovery → 36 results → complete | In-progress timeline and complete lab |
| Demo controls | Speed, reset during/after run, host/status filter, sorting | Filtered/empty table; result inspector |
| Honest source labels | Simulation labels always visible in lab | Complete results with source and timing context |
| Architecture | Actual source file/component mapping | Public/local environments and shared validation |
| Supporting content | Local CLI instructions, glossary, FAQ, references | Expanded details; lower page sections |
| Restricted scanner | Target/port/auth/timeout/concurrency tests; real loopback only | CLI output captured as text |
| Reduced motion / no WebGL | SVG fallback, no automatic animation | Mobile/reduced motion view |
| Metadata / 404 | HTTP checks and route response | Branded missing-page view |
| No console errors or overflow | Browser error collector and viewport measurements | 1440, 768, 390, 320 px |

Off-happy-path checks: invalid CIDR while a valid calculation is displayed; reset halfway through playback; invalid demo subnet; zero matching filter results; switch tabs during playback; unavailable clipboard; no WebGL; unknown CLI options and public-range rejection before any socket creation.

Publication claims require verified remote evidence. Authentication failures must be reported honestly. Production builds and browser checks are reported separately from unit test results.
